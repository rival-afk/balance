# Balance

Физическая игра на Godot 4: вы двигаете платформу и удерживаете **двухзвенный маятник** вертикальной стойкой как можно дольше. Баллы — за вертикальность; серия идеальных кадров наращивает множитель.

## Что изменилось

- Маятник стартует **вертикально вверх** (стойка на платформе).
- **Уровни помощи** (0..4): лёгкий PD-контроллер против наклона — от «чистой физики» до «почти автопилот». Переключение: **↑ / ↓** на клавиатуре, либо `POST /assist` через API (можно выбирать для каждой игры отдельно).
- Роя по `Tab` больше нет: параллельные игры создаются через `--spawn=N` при старте или `POST /spawn` по API (как в rocket-landing).

## Управление

| Клавиша | Действие |
| --- | --- |
| ← / → | Тяга платформы (сила, инерция через `linear_damp`) |
| ↑ / ↓ | Уровень помощи удержанию (0 Нет → 4 Максимум) |
| `Esc` | Выход |

## Как играть

1. Игра стартует со стойкой маятника вертикально.
2. Держите платформу под маятником, гасите раскачивания мелкими движениями.
3. Баллы: `вертикальность² × 12 × множитель`; серия «идеальных» кадров (вертикальность > 0.90) наращивает множитель до ×5.
4. Рекорд — общий на процесс, сохраняется в `user://balance_best.json`.

## Уровни помощи

| level | Имя | Эффект |
|-------|-----|--------|
| 0 | Нет | чистая физика, самая трудная |
| 1 | Лёгкий | лёгкая PD-помощь (стартовая) |
| 2 | Средний | средняя помощь |
| 3 | Сильный | почти полностью удерживает стойку |
| 4 | Максимум | маятник практически не падает |

## Телеметрия / API

Встроенный HTTP API (порт **8787** по умолчанию; `BALANCE_PORT` или `--port=N`) как у rocket-landing: `/health`, `/state`, `/control`, `/speed`, `/spawn`, `/respawn`, `/reset`, `/assist`, `/lane`. См. [api_docs.md](api_docs.md). Апи умеет ускорять симуляцию (`/speed`, `time_scale`) и создавать параллельные игры в одном процессе.

## Сборка (Windows)

```
godot --headless --path . --import
godot --headless --path . --export-release "Windows Desktop" build/Balance.exe
```

Требуются export-шаблоны Godot 4.7.2 (`%APPDATA%\Godot\export_templates`). Текущий пресет: `export_presets.cfg` (Windows Desktop, x86_64).

## Запуск из редактора

Открыть `main.tscn` в Godot 4.7.2 → F5.

## Структура проекта

```
main.tscn            — корень + HUD (оркестрация лейнов)
game.gd              — менеджер лейнов, сетка, HTTP API
lane.tscn / lane.gd  — одна игра (платформа, маятник, очки, ассистент)
platform_body.gd     — платформа: RigidBody2D, рельс по Y (в `lane.tscn`)
api_host.gd          — автолоад BalanceApiHost (переживает reload)
hud_gauge.gdshader   — шкала вертикальности (GPU)
hud_stress.gdshader  — накал корпуса по напряжению (GPU)
felt.gdshader        — фон-«войлок» (GPU)
arm1.svg, arm2.svg, platform.svg, axis.svg
```

## Как это устроено (коротко)

- Платформа — настоящий `RigidBody2D`: стрелки прикладывают силу, инерция через `linear_damp`; скорость ограничена тягой (терминальная ≈ 300 px/s); блокированы ось Y и рыскание.
- Два плеча на `PinJoint2D`; платформа/стены/руки не сталкиваются друг с другом — маятник свободно проходит вертикаль и свисает под палубой.
- Ассистент — вращающий момент на плечо: `τ = −(Kp·наклон + Kd·ω)`, уровни задают Kp/Kd/предел момента.
- Баллы: `вертикальность² × 12 × множитель`; серия «идеальных» кадров (вертикальность > 0.90) наращивает множитель до ×5.
- Физика — CPU, рендер-метрики (шкала, накал, войлок) — GPU.
