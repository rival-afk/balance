# Balance — HTTP API

Внешний API для управления игрой **Balance** и чтения её данных: счёт, наклон, вертикальность, запуск параллельных игр (swarm), ускорение симуляции, уровни помощи. Версия API: **1.0.0** (`config/version` в `project.godot`).

## Запуск

```powershell
# обычная игра (окно)
& "путь\к\Godot_v4.7.2-stable_win64_console.exe" --path "путь\к\balance"

# headless (сервер без окна) + сразу 3 игры
& "..." --headless --path "..." -- --spawn=3

# другой порт API (по умолчанию 8787)
& "..." --path "..." -- --port=8091

# кто-то занял порт — выйти сразу (для непоседливых запусков)
& "..." --path "..." -- --quit-if-port-busy
```

Также учитывается переменная окружения `BALANCE_PORT` (`--port=` имеет приоритет).

- API слушает на всех интерфейсах порта (в выводе — `Balance API: http://127.0.0.1:8787`);
- если порт занят, игра **не падает**: API не стартует, игра идёт как обычно (`--quit-if-port-busy` — выйти сразу);
- API без авторизации: не выставляйте порт наружу.

При старте печатается `Balance 1.0.0` + строка про API.

## Протокол

- `GET`/`POST`/`DELETE`, тело — JSON (Content-Type не критичен), ответ — `application/json`;
- **каждое соединение закрывается после ответа** (`Connection: close`);
- TCP_NODELAY включён на серверных сокетах — ответы не ждут НАГЛЯ;
- позиции в px (`+y` вниз), скорости в px/s, углы в градусах в ответах API (`arm*_deg`), вертикальность — безразмерная [0;1], временные величины — в секундах;
- значения в `/state` — **на физический тик** (60 Гц): повторный запрос в тот же тик почти бесплатен.

## Эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | имя, версия, список эндпоинтов |
| GET | `/health` | живость, версия, `time_scale`, число игр, рекорд |
| GET | `/state` | состояние **всех** игр |
| GET | `/state?lane=N` | состояние игры `N` |
| POST | `/control` | управление игрой `N`: направление тяги |
| POST | `/speed` | ускорение/замедление симуляции |
| POST | `/assist` | уровень помощи удержанию (0..4), на lane или на все |
| POST | `/spawn` | запустить новую параллельную игру |
| POST | `/respawn` | пересоздать игру `N` |
| POST | `/reset` | `{}` — перезагрузка сцены; `{lane}` — пересоздание игры `N` |
| DELETE | `/lane?lane=N` | удалить игру `N` (нельзя удалить последнюю) |
| POST | `/lane/delete` | то же через POST `{"lane":N}` |

### GET `/`

```json
{"name":"balance","version":"1.0.0","docs":"api_docs.md",
 "endpoints":["/health","/state","/state?lane=N","/control","/speed","/spawn","/respawn","/reset","/lane"]}
```

### GET `/health`

```json
{"ok": true, "version": "1.0.0", "time_scale": 1.0, "lanes": 2, "best": 421.32}
```

### GET `/state`

```json
{
  "best": 421.32,
  "time_scale": 1.0,
  "lanes": [ { ... }, { ... } ]
}
```

`/state?lane=N` — то же для одной игры (или `404 {"error":"lane not found"}`).

#### Поля lane

| Поле | Смысл |
|------|-------|
| `lane` | номер игры (0 = главная, ids не переиспользуются) |
| `verticality` | вертикальность маятника, [0;1]: 0 — свисает вниз, 1 — стойка вертикально |
| `tilt_deg` | текущий угол от вертикали вверх, градусы (0..180) |
| `tilt_rate_deg_s` | угловая скорость, °/с |
| `lateral_velocity_px_s` | горизонтальная скорость платформы, px/с |
| `score` | счёт игры |
| `best` | общий рекорд процесса |
| `multiplier` | множитель (×1…×5) |
| `perfect_streak_s` | длина текущей идеальной серии, с |
| `total_perfect_s` | суммарно идеальных секунд |
| `balance_time_s` | секунд с создания игры |
| `faults` / `fault_time_s` | входы в опасную зону и суммарно секунд в ней |
| `platform_x` | мировая X платформы, px |
| `arm1_deg` / `arm2_deg` | абсолютные углы плеч, градусы (180° = стойка вертикально) |
| `assist` / `assist_name` | уровень помощи удержанию (0..4) и его имя |
| `time_scale` | текущее ускорение симуляции |

### POST `/control`

```json
{"lane": 0, "direction": 1}
```

- `lane` — номер игры (по умолчанию `0`),
- `direction` — `-1` (влево), `0` (стоп), `+1` (вправо); клавиатура работает параллельно только для игры 0,
- **ответ — снимок состояния игры ПОСЛЕ применения**.

### POST `/speed`

```json
{"scale": 4.0}
```

`Engine.time_scale`, клампится в [0.05, 20]. Для тренажёра 2–8.

### POST `/assist`

```json
{"lane": 1, "level": 4}   -> {"ok": true, "lane": 1, "assist": 4}
{"level": 2}              -> {"ok": true, "lanes": 3, "assist": 2}   (все игры)
```

Уровни помощи удержанию:

| level | Имя | Эффект |
|-------|-----|--------|
| 0 | Нет | чистая физика |
| 1 | Лёгкий | лёгкий PD-контроллер против наклона |
| 2 | Средний | средняя сила помощи |
| 3 | Сильный | почти полностью удерживает стойку |
| 4 | Максимум | маятник практически не падает |

Уровни реализованы вращающим моментом на каждое плечо: `τ = -(Kp·наклон + Kd·ω)`.

### POST `/spawn` → `POST /respawn` → `POST /reset`

```json
POST /spawn            {}                 -> {"lane": 5, "lanes": 5}
POST /respawn          {"lane": 2}        -> {"ok": true, "lane": 2}
POST /reset            {}                 -> {"ok": true, "reloading": true}
POST /reset            {"lane": 2}        -> {"ok": true, "lane": 2}
```

`/reset {}` — полная перезагрузка сцены (Phase: пока сцена мертва (~50–200 мс), API отвечает `503 {"error":"scene reloading","retry_after_ms":500}` с `Retry-After: 1`; клиенту — ретрай с backoff).
`/respawn` — пересоздание игры **в том же id**.

### DELETE `/lane?lane=N`  /  POST `/lane/delete`

```json
{}-> {"ok": true, "lane": 2, "lanes": 3}
   -> 400 {"error":"cannot delete the last lane"}
   -> 404 {"error":"lane not found"}
```

Удаляет игру целиком; остальные не трогает; `id` убранной игры больше никогда не выдаются.

## Запуск с вертикальным спавном

Маятник стартует **вертикально вверх** (стойка), а задача игрока — удержать его вертикально. Сложность регулируется уровнем помощи (↑/↓ на клавиатуре, `/assist` через API).

## Примеры

```bash
curl http://127.0.0.1:8787/health
curl http://127.0.0.1:8787/state
curl "http://127.0.0.1:8787/state?lane=0"
curl -X POST -d '{"lane":0,"direction":1}'   http://127.0.0.1:8787/control
curl -X POST -d '{"scale":4}'                 http://127.0.0.1:8787/speed
curl -X POST -d '{"lane":0,"level":2}'        http://127.0.0.1:8787/assist
curl -X POST -d '{}'                          http://127.0.0.1:8787/spawn
curl -X POST -d '{"lane":2}'                  http://127.0.0.1:8787/respawn
curl -X DELETE "http://127.0.0.1:8787/lane?lane=3"
```

## Коды

- `200` — успех; `400` — битый JSON / `lane required` / удаление последней игры; `404` — игра не найдена / неизвестный путь; `503` — сцена перезагружается.

## Замечания

- `best` общий на все игры, сохраняется в `user://balance_best.json`;
- рекорд/множитель растут в ходе игры; reset не трогает рекорд;
- игра работает в headless без окна;
- для тренажёра групп рекомендуется задавать каждой игре свой `--port=`.
